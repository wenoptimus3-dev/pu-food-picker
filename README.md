# 靜宜吃什麼？PU Food Lucky Draw

### 專案簡介
專為靜宜大學學生打造的明亮活潑風「今天吃什麼」美食抽籤單頁網頁，收錄校門口與北勢東路商圈精選 30 間真實名店，具備趣味紙籤飛出展開動效、早中晚時段篩選與最近吃過足跡紀錄。

---

### 功能清單
1. **切換早午晚時段分類標籤**：動態過濾對應時段之周邊推薦店家與抽籤候選池（全部 / 早餐 / 午餐 / 晚餐與宵夜）。
2. **抽取命運美食籤牌動效**：觸發籤筒劇烈晃動，紙籤向上拔起飛出並 3D 翻轉展開為幸運籤卡，伴隨五彩碎屑與原生音效。
3. **記錄最近吃過足跡與智慧避開**：一鍵標記「就決定吃這家！」儲存至瀏覽器本地（免登入），並支援抽籤時自動排除最近 3 次吃過的店家。
4. **瀏覽店家詳情與 Google 導航**：完整展示招牌必點、均消價格、距校門步行時間，支援一鍵開啟 Google 地圖即時搜尋導航。

---

### 驗收方式
1. **介面與店家資料檢驗**：開啟 `index.html`，確認頁面為明亮活潑的暖黃/亮橘色調，且正確收錄 30 間沙鹿北勢東路、英才路與國王商圈代表性店家。
2. **時段過濾與搜尋測試**：切換「早餐」、「午餐」或「晚餐」標籤，或在搜尋框輸入「湯包」、「牛肉麵」等關鍵字，確認清單與籤池即時聯動。
3. **飛籤展開與吃過紀錄測試**：點擊「抽出今日美食」，確認有籤筒搖晃、紙籤飛出並 3D 展開為彈窗的動畫；點擊「就決定吃這家！」後，確認右上角「吃過紀錄」數字增加，點開可檢視時間軸與招牌餐點。

---

### 怎麼使用
1. **開啟網站**：直接以任何瀏覽器雙擊開啟 `index.html`，或點擊部署在 GitHub Pages 的公開連結。
2. **選擇時段**：在畫面頂部點選欲覓食的時段（例如：午餐便當）。
3. **搖筒抽籤**：點擊畫面上方的籤筒或「🎲 抽出今日美食」大按鈕。
4. **揭曉幸運籤**：紙籤飛出展開後，查看命運推薦的店家、學生力推招牌與均消。
5. **記錄或導航**：
   - 點擊「🗺️ Google 導航」在新分頁查看路線地圖。
   - 點擊「🥢 就決定吃這家！」記下足跡，下次抽籤時系統會自動為您換換口味！
